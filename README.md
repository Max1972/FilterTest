# OpenMB

Work in progress: original multiband dynamics plugin targeting macOS Monterey 12.0+, Apple Silicon and Logic Pro AUv2. This initial implementation contains a portable dynamics core and a JUCE plugin skeleton. It is not a multiband processor or release yet.

See BUILDING.md and TEST_RESULTS.md. JUCE is pinned to 7.0.12; distribution requires compliance with its applicable licence. No FabFilter code or artwork is used.
